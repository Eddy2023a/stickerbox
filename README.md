# 表情匣 StickerBox

macOS 菜单栏表情工具：搜索 QQ 表情、复制标准尺寸表情，也可以把文字合成到内置模板。支持飞书选词右键搜索，点击表情后自动切回飞书粘贴，确认图片已插入后自动发送；可在菜单栏右键菜单中关闭自动发送。

## 功能示意

在飞书输入框选中文字，右键选择「表情搜索」。替代菜单保留复制、剪切、粘贴，并提供「飞书原右键菜单」入口。

![飞书右键菜单中的表情搜索入口](docs/images/feishu-context-menu.png)

搜索窗在鼠标附近打开，显示表情结果。点击一个表情后复制标准尺寸表情，并在权限允许时切回飞书输入框自动粘贴；自动发送开启时，满足下方检查条件后会发送一次；关闭时由你自行发送。

![搜索“哇哈哈”后的表情结果](docs/images/sticker-search-results.png)

## 本次更新（2026-11-06）

- 飞书右键选词搜索：后台记录原输入框和选区，减少弹窗前的界面遍历与剪贴板转换；搜索窗在鼠标附近打开。
- 点击表情先复制，再恢复原输入框及未变化的文字选区并粘贴；图片一直保留在剪贴板，可手动重复粘贴。
- 自动发送改为直接执行一次 **Enter**，不再查找发送按钮。须确认输入框只有本次图片、没有其他文字且焦点未变；可在菜单栏右键菜单中关闭。
- 表情最长边限制为 **160 像素**，保持比例，小图不放大；GIF 保留动画帧与时序，PNG 兼容数据和文件地址使用相同的小尺寸版本。
- 保留低资源策略：不常驻轮询，关闭搜索窗后释放资源，缩略图缓存上限 4 MB，下载并发最多 2。

## 为什么做这个

切换到飞书后，少了随手搜索表情包的方便，工作聊天也少了几分趣味。希望飞书早日安排上这个功能；在那之前，先用「表情匣」过渡一下，把斗图的快乐找回来。

## 适用范围

- Apple Silicon（M 系列）Mac，macOS 13 或更新版本；暂不提供 Windows / Intel 版本。
- 在线搜索需要安装并登录 Mac QQ；内部接口仅在 QQ **7.0.0-52194** 验证过，其他版本可能不兼容。
- 需要 Apple 命令行开发工具（Swift、codesign）及 `/usr/bin/python3`。
- 当前是实验版本，未经过 Apple 公证。QQ-debug 是在你自己电脑上复制、安装连接组件并重新签名的 QQ 副本，不是腾讯官方提供的另一个下载版本。

## 首次安装：按顺序操作

### 1. 下载工具源码

在本仓库点 **Code → Download ZIP** 并解压。打开终端，输入 `cd `（末尾一个空格），把解压后的文件夹拖入终端，按回车。之后的命令都在这个文件夹执行。

### 2. 安装开发工具与 QQ

如果还没有开发工具，执行下面命令，按系统提示完成安装：

```sh
xcode-select --install
```

已有工具时会提示已安装，可以继续。执行以下命令检查：

```sh
xcrun swiftc --version
/usr/bin/python3 --version
```

从腾讯官方渠道安装 Mac QQ，将 `QQ.app` 放到「应用程序」。先退出正在运行的 QQ，再创建副本，避免两个副本争用同一账号数据。

### 3. 自动创建 QQ-debug 并安装连接组件

```sh
/usr/bin/python3 setup_qq.py
```

脚本会从 `/Applications/QQ.app` 复制到：

```text
~/Library/Application Support/StickerBox/QQ-debug.app
```

然后保留 QQ 原有权限、增加本地连接所需权限，重新签名副本，安装随 QQ 启动的表情搜索组件。首次复制需要一些时间和额外磁盘空间。**不会修改 `/Applications/QQ.app`，不需要 sudo，也不需要关闭 SIP。**

如果 QQ 不在「应用程序」，可以指定位置，例如：

```sh
/usr/bin/python3 setup_qq.py --source "$HOME/Downloads/QQ.app"
```

仓库不附带 QQ 本体或任何人的登录数据。每位同事应在自己的 Mac 上创建副本、登录自己的账号。副本沿用 QQ 的应用标识与容器，**不是隔离的第二账号环境**，日常使用时请退出原版 QQ，只运行副本。

### 4. 打开副本并登录

```sh
open "$HOME/Library/Application Support/StickerBox/QQ-debug.app"
```

在弹出的 QQ 窗口完成登录。无需打开 QQ 的表情面板，无需 LLDB 或调试器。首次复制后的安装流程尚未在全新 Mac 上完整验证；遇到报错请提供报错文字、macOS 与 QQ 版本。

### 5. 构建并打开表情匣

```sh
zsh build.sh
open "build/表情匣.app"
```

可在 Finder 中把 `build/表情匣.app` 拖到「应用程序」。顶部菜单栏出现笑脸即启动成功，不显示 Dock 图标。

如果系统阻止打开你刚构建的应用，可在「系统设置 → 隐私与安全性」查看该应用对应的提示，确认来源后使用系统提供的打开选项。不要全局关闭系统安全检查。

## 怎么用

1. 点菜单栏笑脸，输入关键词，按回车或点放大镜。
2. 「全部表情」显示在线结果；点一个表情复制；从飞书打开搜索并已授权辅助功能时，会自动回到原聊天输入框粘贴，自动发送开启且检测通过时发送一次。其他应用或权限不足时可手动粘贴。
3. 也可以先复制一段 100 字以内的文字，再点笑脸自动搜索。
4. 「生成表情」可用内置 8 个模板合成文字，无需 QQ 在线；点击模板完成合成并复制。
5. 右键菜单栏笑脸 →「启用飞书右键菜单…」，允许辅助功能权限。飞书前台时右键会出现替代菜单，包含复制、剪切、粘贴和「表情搜索」；点击搜索后在鼠标旁打开搜索窗。可通过「飞书原右键菜单」使用飞书其他操作。当前替代范围为飞书窗口内的右键，并不限于输入框。
   - 重新编译后如果系统设置显示已授权、菜单仍未生效，请将表情匣辅助功能开关关闭再打开；仍无效则移除旧条目并重新添加 `/Applications/表情匣.app`。
   - 优先直接读取选中文字，无法读取时使用模拟复制并恢复可用的原剪贴板格式；未能读取或超过 100 字时打开空搜索框，支持手动输入。
6. 右键笑脸可切换「选择表情后自动发送（Enter）」，默认开启并记住设置；也可打开 QQ 调试副本或退出工具。

在线搜索每次最多 50 个结果，目前只取第一页。复制包含最长边不超过 160 像素的 GIF/图片、PNG 兼容格式及本地文件地址；目标软件若仅接收 PNG，会显示静态图。关闭窗口会清理缩略图，图片缓存在用户缓存目录，按约 80 MB 清理旧文件。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 提示 QQ 调试副本缺失 | 在源码目录运行 `/usr/bin/python3 setup_qq.py`，不要只复制表情匣 App。 |
| 提示副本已经存在 | 安装脚本不会覆盖。只更新连接组件请运行下方更新命令；需要重建时先退出副本，在 Finder 中移走旧 `QQ-debug.app` 再安装。 |
| 提示启动结构或版本不匹配 | 当前版本可能不兼容，请记录 QQ 版本与完整报错；不要强行改启动路径。 |
| QQ 连接尚未就绪 / 搜索失败 | 确认运行的是上述路径的 QQ-debug，已完成登录；退出原版和副本，再单独打开副本，登录后重新搜索。首次登录超过等待时间时，登录完成再搜即可。 |
| 只有模板可用、在线搜索失败 | 模板是本地功能，在线搜索还需要 QQ-debug 登录和连接正常。 |
| QQ 更新后失败 | 原版 QQ 更新不会同步更新旧副本。退出副本，移走旧副本，再从兼容的 QQ 版本重新创建。 |
| 粘贴后动图不动 | 目标应用可能只接受 PNG；换支持 GIF 或文件粘贴的应用验证。 |
| 找不到副本目录 | Finder → 前往 → 前往文件夹，输入 `~/Library/Application Support/StickerBox/`。 |

## 更新连接组件

先彻底退出 QQ-debug，然后在最新源码目录执行：

```sh
/usr/bin/python3 install_qq_bridge.py
open "$HOME/Library/Application Support/StickerBox/QQ-debug.app"
```

更新器会保留原有权限，并在 `repair-backup` 保存原始启动配置。在线服务随 QQ 进程存在，已取消早期临时接口的一小时限制。

## 卸载

退出表情匣和 QQ-debug，删除表情匣 App 和 `~/Library/Application Support/StickerBox/` 中的副本与连接备份即可。QQ 原版保留；不要删除 QQ 共享容器中的账号资料。

## 隐私与实现

点击图标时才读取剪贴板。飞书替代菜单需要辅助功能权限，会拦截飞书前台的右键；右键菜单出现时按需读取当前选区，不持续读取聊天内容。系统服务入口仍保留。在线关键词通过当前 QQ 登录会话提交给 QQ 搜索服务。本地连接仅监听 `127.0.0.1`，请求需要本机生成的随机令牌，连接配置文件限制为当前用户读写。不要分享连接 JSON、令牌、QQ 账号目录或整份 QQ-debug 副本。

代码基于 QQ 内部接口，并非官方 SDK；QQ 更新可能导致失效。旧的 `bridge_lldb.py` 是早期研究辅助代码，当前运行流程不使用它。内置表情素材仅作示例，相关权利归原作者，转用素材时需自行确认授权。

## 自动粘贴与发送规则

从飞书右键入口打开搜索后，会记录原窗口、输入框和文字选区。点击表情后先完成复制，再切回原输入框，原文字未变时恢复选区并粘贴。图片始终留在剪贴板中，自动粘贴或发送失败时仍可手动粘贴。

自动发送默认开启，可在菜单栏右键菜单中关闭。粘贴后须确认原窗口和输入框仍有焦点、剪贴板未变化、输入框只有一张图片且文件路径与本次表情一致、无其他文字，状态稳定后才执行一次 **Enter**。空白换行和零宽占位符不算文字。一张图片附带的装饰控件不会被当成第二张图片。

有其他待发送文字或多张图片、内容无法确认、焦点或剪贴板变化时不触发 Enter。发送动作不重复尝试；使用飞书其他发送快捷键的用户可关闭自动发送、手动发送。

## 图片尺寸

发送与复制统一使用最长边 160 像素的图片，按比例缩小，不放大小图。GIF 按帧处理，保留动画帧、播放间隔和循环信息。PNG 兼容格式和文件地址均使用缩小后的文件，避免目标应用优先读取大原图。

## 资源消耗与诊断

不使用后台定时轮询。授权未生效时仅在应用切换时检查，成功后移除观察者；搜索窗关闭后释放界面、结果和图片缓存，取消请求及过期解码任务。缩略图最大边长 144 px，缓存上限 4 MB / 32 项，最多 2 条下载连接。

本机短时采样：早期已有使用历史的进程约 43 MB；低资源优化后的冷启动、未打开搜索窗约 14 MB，CPU 0–0.1%。两个状态不同，不能据此计算节省比例；14 MB 采样时辅助功能权限未开启，且不包含 QQ。最新完整流程和搜索峰值未做资源基准测试。

缓存目录 `~/Library/Caches/StickerBox/` 中的 `last-context.txt` 记录最近一次右键定位耗时、是否找到输入框与选词字数，`last-action.txt` 记录最近一步结果；均不记录聊天正文。右键定位一次实测约 8 ms，不代表网络搜索或整个弹窗的总耗时。

重新编译和替换 App 后，辅助功能授权可能需要刷新：退出表情匣，在系统设置中移除旧条目，重新添加「应用程序」中的当前版本，再重新打开。
